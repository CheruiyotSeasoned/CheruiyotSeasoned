# Brian Cheruiyot

Backend developer in Nairobi, Kenya. I build payment and tax-compliance integrations, and the backend systems around them.

I've been writing code since 2018. Most of my work is in **Java with Spring Boot and MySQL**, and I also work in **PHP (Laravel and CodeIgniter)**.

### What I work on

- **Tax compliance:** KRA eTIMS (Kenya) and URA EFRIS (Uganda) e-invoicing and fiscalization, including device registration and invoice submission pipelines
- **Payments:** M-Pesa, Pesapal, Stripe, and cryptocurrency payment integrations
- **Backend systems:** loan management and repayment scheduling, restaurant POS with multi-currency support, event registration and booking platforms
- **APIs:** REST APIs, third-party API integrations, webhooks, and database design

### Stack

Java, Spring Boot, JPA/Hibernate, Flyway, MySQL, PHP, Laravel, CodeIgniter, JavaScript
